>Ejecución del servidor backend

 1.Abrir la consola de comandos
 2.Ubicarse en la carpeta del proyecto donde se encuentra el archivo database.py y ejecutar
 3.Despues dirigirse al archivo server.py 
 3.Ejecutar el siguiente comando: python server.py
 4.El servidor se iniciará en la dirección: http://localhost:8000
 5.No cerrar la consola mientras el servidor esté en ejecución

>Ejecución del frontend

 1.Abrir el archivo index.html desde el navegador web.
 2.Navegar por el sitio utilizando el menú principal.
 3.Para probar la suscripción, ingresar un correo electrónico en el formulario ubicado en el footer y presionar el botón “Enviar”

>Visualización de datos almacenados (opcional)

 1.Con el servidor en ejecución, ingresar en el navegador a la ruta: http://localhost:8000/admin
 2.Ingresar la contraseña configurada en el servidor: http://localhost:8000/admin?pass=admin123
 3.Se mostrará la lista de correos electrónicos registrados
